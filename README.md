# xfce-kogti

Тёмная тема «Kogti» для XFCE (целевой дистрибутив — MX Linux 25 / Debian 13, Xfce 4.20).
Один `.deb`, одна команда для применения, одна команда для отката.

Палитра, форма и ассеты берутся из дизайн-бука (`design/`), все числа лежат в одном
файле — `tokens.toml`. Остальное генерируется.

## Установка и применение

На машине с MX Linux:

```bash
sudo apt install ./dist/xfce-kogti_0.1.0_all.deb   # подтянет papirus-icon-theme и xfconf
kogti-apply                                   # тема для текущего пользователя
kogti-apply --system                          # + экран входа (один запрос пароля)
```

То же самое без терминала: в меню приложений два пункта, «Apply Kogti theme» и «Revert Kogti theme»
(оба работают вместе с `--system`).

Откат:

```bash
kogti-apply --revert            # вернуть всё, что менял kogti-apply
kogti-apply --revert --system   # + экран входа
```

Откатывайте тему до удаления пакета (`apt remove xfce-kogti`).

Другие команды:

| Команда | Что делает |
|---|---|
| `kogti-apply --list` | доступные обои и аватары |
| `kogti-apply --wallpaper claws` | обои: `logo` (по умолчанию), `claws`, `tracks`, `rows`, `teeth` |
| `kogti-apply --avatar axe-hex` | аватар: `profile` (по умолчанию), `profile-hex`, `profile-split`, `axe`, `axe-hex`, `axe-square` |
| `kogti-apply --dry-run` | показать, что будет изменено, ничего не трогая |
| `kogti-apply --status` | что сейчас применено |
| `kogti-apply --no-restart` | не перезапускать панель и рабочий стол |

Повторный запуск безопасен (идемпотентен). Исходные значения запоминаются в
`~/.local/state/kogti/journal.json` и возвращаются при `--revert`.

## Что входит в тему

- **GTK3 / GTK4 / libadwaita** — перекрашенный [adw-gtk3](https://github.com/lassekongo83/adw-gtk3) v6.5:
  палитра Kogti, радиус скругления не больше 2 px, янтарная линия под активным заголовком, стили панели XFCE.
  Для приложений libadwaita блок цветов записывается в `~/.config/gtk-4.0/gtk.css` (с маркерами, пользовательские правила не затрагиваются).
- **xfwm4** — плоские рамки, заголовок 30 px, янтарная линия 2 px под активным окном, квадратные кнопки.
- **Иконки** — `Kogti` наследует `Papirus-Dark`; папки Papirus перекрашены в янтарь, добавлены `kogti-menu`,
  `start-here`, `distributor-logo`.
- **Whisker-меню** — значок `kogti-menu` (только у плагина `whiskermenu`).
- **Терминал** — цветовая схема в `terminalrc` (шрифт сохраняется).
- **Qt** — палитра для qt5ct/qt6ct; переменная `QT_QPA_PLATFORMTHEME` пишется в `~/.xsessionrc` и действует после перелогина.
- **Обои и аватар** — пользовательский `~/.face`, а с `--system` ещё и значок в AccountsService.
- **Экран входа** — `lightdm-gtk-greeter`: тема, значки, фон, аватар по умолчанию.

Права root нужны только для `--system`, и только для файлов, которые поставляет пакет:
пути, переданные пользователем, привилегированная часть не принимает.

## Сборка

Нужен только Python 3.11+ (stdlib + Pillow). `dpkg-deb` не требуется — `.deb` собирается на чистом Python,
поэтому собирать можно и на Windows.

```bash
pip install pillow
python tools/fetch_bases.py     # один раз: скачать adw-gtk3 и Papirus (sha256 зафиксирован в kogti/bases.py)
python build.py                 # dist/xfce-kogti_0.1.0_all.deb  (+ dist/tree/ с распакованным содержимым)
python tools/verify.py          # статические проверки + прогон kogti-apply на поддельном xfconf
python tools/preview.py         # dist/preview.html — визуальный просмотр палитры, папок, рамок, обоев
```

Сборка воспроизводима: два запуска подряд дают побайтово одинаковый `.deb` (метка времени по умолчанию
фиксирована, переопределяется через `SOURCE_DATE_EPOCH`).

## Как менять тему

Правьте `tokens.toml` и запускайте `python build.py`.

- `[brand]` — основные цвета (ink `#0A0A09`, amber `#FFAA1D`, bone `#F4F1E8`); нейтральные поверхности вычисляются как их смесь.
- `[status]`, `[ansi_extra]` — цвета ошибок/успеха/информации и ANSI magenta/cyan.
- `[geometry]` — радиус, высота заголовка, толщина рамки, толщина акцентной линии.
- `[assets]` — аватар по умолчанию, значок меню, логотип для обоев, сила узора.

## Что проверено, а что нет

Проверено на Windows (88 проверок в `tools/verify.py`):

- структура и метаданные `.deb`: формат ar, порядок членов, md5sums всех 1129 файлов, владелец root, права;
- GTK-стили: баланс скобок, нет остатков синего Adwaita, все радиусы не больше 2 px, все ресурсы и `@import` разрешаются;
- контраст основных пар цветов (текст на окне, заголовке, всплывающем меню, на акценте, статусные цвета, терминал);
- xfwm4: полный набор из 61 файла, размеры заголовка, углов, рамок и кнопок;
- иконки: корректный XML во всех 956 SVG, нет оставшегося синего Papirus, `index.theme` объявляет все каталоги;
- `kogti-apply` на подставном xfconf: применение, повторное применение, откат до исходного состояния,
  сохранение пользовательских строк в `settings.ini` и `gtk.css`, правки только плагина Whisker;
- визуальный просмотр через `tools/preview.py`, включая числовую проверку янтарной линии под заголовком.

**Не проверено на реальной системе** (нет Linux на машине сборки): установка через `dpkg`/`apt`,
отрисовка GTK3/GTK4, выравнивание кнопок xfwm4, реальные вызовы `xfconf-query` с массивами,
запись конфигурации Whisker, экран входа. Первый запуск на MX стоит делать с `--dry-run`.

## Допущения и ограничения

- Название «Kogti», цвета статусов, ANSI magenta/cyan, аватар и обои по умолчанию выбраны мной, в дизайн-буке их нет.
- Курсор не темизируется, шрифты не меняются (`[desktop]` в `tokens.toml` зарезервирован).
- Qt-палитра работает через qt5ct/qt6ct; Kvantum и Flatpak-приложения не настраиваются.
- libadwaita до 1.6 не понимает CSS-переменные: цвета применяются через `@define-color`, часть приложений может выглядеть иначе.
